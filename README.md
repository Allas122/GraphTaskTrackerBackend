# Это мой маленький проект реализованный в рамках модуля "Графы"
# Технологии:
1. .NET 9
2. ASP.NET
3. FluentValidator
4. Entity Framework Core
5. Scalar, OpenApi
6. PostgresSQL

## Что умеет:
1. Базовая авторизация по JWT
2. Хранить произвольные графы(CRUD)
3. Может стримить состояние графа через SSE(Server-sent events).
## Чего я придерживался:
1. Старался имплементировать большую часть принципов Clean Architecture.
2. Я хотел сделать в первую очередь интерактивный стейт, из за чего и был выбран контракт: Sync post Get SSE.
